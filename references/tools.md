## 1. HRDK 역량 내비게이터 (경력 로드맵)

### `recommend_qualifications`

사용자의 경력·직무 키워드를 NCS 능력단위와 Q-Net 자격 종목에 연결해 근거가 있는 자격 후보를 추천합니다. 응시자격 판정이 아니라 탐색용 추천입니다. 예: '시설관리 경력에 맞는 자격 추천해줘'

| 파라미터 | 구분 | 설명 |
|---|---|---|
| `careerQuery` | **필수** | 현재 직무·경력·관심업무 설명 |
| `limit` | 선택 | 추천 자격 수 (기본 5) |

### `build_career_roadmap`

경력·직무로 자격 후보를 추천하고, 최상위 후보가 어떤 법정 선임 자리로 이어지는지와 추가로 필요한 실무경력까지 한 번에 정리합니다. 자격 탐색과 법령 대조를 한 호출로 잇습니다. 예: '전기설비 시설관리 5년인데 뭘 따서 어디까지 갈 수 있어?'

| 파라미터 | 구분 | 설명 |
|---|---|---|
| `careerQuery` | **필수** | 현재 직무·경력·관심업무 |
| `experienceYears` | 선택 | 자격 취득 이후 보유한 실무경력(년). 입력하면 지금 선임 가능한 자리를 판정합니다. |
| `limit` | 선택 | 자격 후보 수 (기본 3) |

### `check_legal_requirements`

국가자격으로 갈 수 있는 법정 선임 자리와 추가로 필요한 실무경력, 미선임 제재를 법령 조문 근거와 함께 조회합니다. 현재 전기안전관리법·산업안전보건법·화재예방법을 수록하고 있습니다. 법률 자문이 아니라 법령 조문 대조 결과입니다. 예: '전기기사로 갈 수 있는 선임 자리 알려줘'

| 파라미터 | 구분 | 설명 |
|---|---|---|
| `qualificationName` | **필수** | 자격증 이름 (예: '전기기사', '산업안전기사', '소방설비기사') |
| `experienceYears` | 선택 | 자격 취득 이후 보유한 실무경력(년). 입력하면 지금 선임 가능한 자리를 판정합니다. |

## 2. 국가자격시험 (Q-Net)

### `search_qualification`

키워드로 국가자격 종목(자격증)을 검색해 정확한 종목명·종목코드·계열(기사/산업기사/기능사 등)·직무분야를 알려줍니다. 종목명이 불확실할 때 다른 도구보다 먼저 사용하세요. 예: '전기 관련 자격증 뭐 있어?', '조리 자격증 종류 알려줘'

| 파라미터 | 구분 | 설명 |
|---|---|---|
| `query` | **필수** | 검색 키워드 (예: '전기', '정보처리', '조리') |
| `limit` | 선택 | 최대 결과 수 (기본 15) |

### `get_exam_schedule`

국가자격시험의 회차별 원서접수 기간, 필기/실기 시험일, 합격자 발표일을 조회합니다. 자격증 이름만 알면 됩니다(종목코드 불필요). 기사·산업기사·기능사 등 국가기술자격은 등급별 공통 일정으로 안내될 수 있습니다. 예: '정보처리기사 접수 언제야?', '올해 전기기사 실기 시험일 알려줘'

| 파라미터 | 구분 | 설명 |
|---|---|---|
| `qualificationName` | 선택 | 자격증 이름 (예: '정보처리기사'). 전체 일정을 보려면 생략 |
| `jmCd` | 선택 | 종목코드 (search_qualification 결과로 알 수 있음) |
| `year` | 선택 | 시행년도 (기본: 올해) |
| `category` | 선택 값: 국가기술자격, 과정평가형, 일학습병행, 국가전문자격 | 자격 구분 (기본: 국가기술자격) |

### `get_qualification_info`

국가자격 종목의 개요, 수행직무, 진로 및 전망 등 상세정보를 조회합니다. 예: '정보처리기사는 뭐 하는 자격이야?', '전기기사 따면 어디 취업해?'

| 파라미터 | 구분 | 설명 |
|---|---|---|
| `qualificationName` | 선택 | 자격증 이름 (예: '정보처리기사') |
| `jmCd` | 선택 | 종목코드 (이미 아는 경우) |

### `get_exam_fee`

국가기술자격 종목의 필기·실기 응시수수료를 조회합니다. 예: '정보처리기사 응시료 얼마야?'

| 파라미터 | 구분 | 설명 |
|---|---|---|
| `qualificationName` | 선택 | 자격증 이름 (예: '정보처리기사') |
| `jmCd` | 선택 | 종목코드 (이미 아는 경우) |

### `get_pass_rate`

국가기술자격의 연도별·회차별 응시자 수, 합격자 수, 합격률을 조회합니다. 종목을 지정하지 않으면 국가기술자격 전체 총괄 통계를 보여줍니다. 예: '전기기사 합격률 어때?', '작년에 국가기술자격 몇 명이나 응시했어?'

| 파라미터 | 구분 | 설명 |
|---|---|---|
| `qualificationName` | 선택 | 자격증 이름 (예: '전기기사'). 전체 통계는 생략 |
| `jmCd` | 선택 | 종목코드 (이미 아는 경우) |
| `year` | 선택 | 기준년도 (기본: 작년 — 통계는 연도 마감 후 확정) |

### `find_test_sites`

지역명으로 한국산업인력공단 지사와 소속 시험장을 찾습니다. 지사 주소·연락처와 시험장 목록을 알려줍니다. 예: '서울에 시험장 어디 있어?', '부산 CBT 시험장 알려줘'

| 파라미터 | 구분 | 설명 |
|---|---|---|
| `region` | **필수** | 지역명 또는 지사명 (예: '서울', '부산', '경기', '서울서부') |

### `get_disqualification_info`

국가자격 종목의 응시 결격사유와 유사종목 정보를 조회합니다. 예: '공인노무사 결격사유 있어?', '이 자격이랑 비슷한 자격 뭐 있어?'

| 파라미터 | 구분 | 설명 |
|---|---|---|
| `qualificationName` | **필수** | 자격증 이름 (예: '공인노무사') |

### `get_exam_questions`

국가기술자격 시험의 공개문제(기출문제) 공고 목록을 조회합니다. 종목명으로 검색할 수 있습니다. 예: '제빵기능사 기출문제 있어?', '최근에 공개된 시험문제 뭐 있어?' 실제 문제 파일은 Q-Net(q-net.or.kr) 자료실에서 제목으로 검색해 내려받을 수 있습니다.

| 파라미터 | 구분 | 설명 |
|---|---|---|
| `qualificationName` | 선택 | 자격증 이름 (예: '제빵기능사'). 생략하면 최근 공개문제 전체 |
| `jmCd` | 선택 | 종목코드 (아는 경우) |
| `limit` | 선택 | 최대 결과 수 (기본 15) |

## 3. 해외취업 (월드잡플러스)

### `search_overseas_jobs`

월드잡플러스의 해외취업 채용공고(현재 모집 중)를 국가·직종·키워드로 검색합니다. 예: '일본 IT 해외취업 공고 있어?', '싱가포르에서 일할 수 있는 자리 찾아줘'

| 파라미터 | 구분 | 설명 |
|---|---|---|
| `query` | 선택 | 키워드 (공고명·회사명·직종에서 검색) |
| `country` | 선택 | 국가명 (예: '일본', '미국', '베트남') |
| `jobField` | 선택 | 직종 키워드 (예: 'IT', '간호', '조리') |
| `limit` | 선택 | 최대 결과 수 (기본 15) |

### `get_overseas_employment_stats`

해외취업 통계를 조회합니다. 기본은 연도·국가별, monthly=월별 추이, dimension으로 세부 차원 선택 — job(직종별)·age(연령별)·training(연수 참여)·placement(알선)·pipeline(단계별 구직)·training_jobs(연수 취업)·returnees(국내복귀)·resigned(퇴직). 예: '작년에 해외취업 몇 명이나 했어?', '직종별로 누가 많이 나가?', '연령대별 해외취업 분포'

| 파라미터 | 구분 | 설명 |
|---|---|---|
| `year` | 선택 | 연도 (기본: 올해, 없으면 작년 자동) |
| `country` | 선택 | 특정 국가만 보려면 (예: '일본') — 국가별 통계에만 적용 |
| `monthly` | 선택 | 월별 추이로 보기 (국가 구분 없음, 2012년부터 제공) |
| `dimension` | 선택 값: job, age, training, placement, pipeline, training_jobs, returnees, resigned, monthly_country, monthly_postings | 세부 차원 (지정 시 country·monthly 무시) |
| `limit` | 선택 | 세부 차원 결과 수 (기본 20) |

### `search_overseas_companies`

해외취업 연계 구인기업(진출기업·현지기업)을 국가·키워드로 검색합니다. 예: '베트남에 있는 한국 기업 알려줘', '물류 쪽 해외 기업'

| 파라미터 | 구분 | 설명 |
|---|---|---|
| `query` | 선택 | 키워드 (기업명·업종에서 검색) |
| `country` | 선택 | 국가명 (예: '인도네시아') |
| `limit` | 선택 | 최대 결과 수 (기본 15) |

### `search_overseas_top_jobs`

공단이 선별한 해외취업 우수일자리(급여·비자 등 조건이 검증된 공고)를 국가·직종·키워드로 검색합니다. 일반 공고는 search_overseas_jobs를 쓰세요. 예: '캐나다 우수일자리 있어?', '검증된 일본 IT 공고 알려줘'

| 파라미터 | 구분 | 설명 |
|---|---|---|
| `country` | 선택 | 국가명 (예: '일본', '캐나다') |
| `jobField` | 선택 | 직종 키워드 (예: 'IT', '물류') |
| `company` | 선택 | 회사명 키워드 |
| `query` | 선택 | 공고명 키워드 |
| `limit` | 선택 | 최대 결과 수 (기본 15) |

### `get_overseas_job_fairs`

해외취업 설명회(온라인·지역별)와 해외취업아카데미 프로그램 일정을 조회합니다. 예: '해외취업 설명회 언제 해?', '온라인으로 들을 수 있는 해외취업 교육 있어?'

| 파라미터 | 구분 | 설명 |
|---|---|---|
| `query` | 선택 | 설명회명·장소 키워드 |
| `includePast` | 선택 | 지난 일정도 포함 (기본 false — 예정된 것만) |
| `limit` | 선택 | 최대 결과 수 (기본 15) |

### `get_overseas_country_info`

국가별 해외취업·진출 정보(비자·현지 정보) 안내 페이지 링크를 알려줍니다. 예: '뉴질랜드 취업 비자 정보 어디서 봐?', '미국 진출 정보 알려줘'

| 파라미터 | 구분 | 설명 |
|---|---|---|
| `country` | 선택 | 국가명 (생략하면 전체 목록) |

### `get_overseas_hiring_stats`

해외 구인기업별 구인 인원수 통계를 조회합니다. 기업명으로 검색할 수 있습니다. 예: '해외 구인 수요 얼마나 돼?', '이 회사 몇 명 뽑아?'

| 파라미터 | 구분 | 설명 |
|---|---|---|
| `company` | 선택 | 기업명 키워드 (생략하면 전체 요약) |

### `get_overseas_settlement_support`

해외취업 정착지원금 지급 실적을 국가별·직종별·차수별로 조회합니다. 예: '정착지원금 어느 나라에 많이 나갔어?', '직종별 정착지원금 실적 보여줘'

| 파라미터 | 구분 | 설명 |
|---|---|---|
| `year` | 선택 | 연도 (기본: 올해, 없으면 작년 자동 — 국가별·직종별에 적용) |
| `groupBy` | 선택 값: nation, job, round, monthly | nation(국가별)·job(직종별)·round(차수별)·monthly(월별). 기본 nation |
| `limit` | 선택 | 최대 결과 수 (기본 20) |

### `search_overseas_resources`

해외취업 관련 콘텐츠와 프로그램을 종류별로 검색합니다 — 뉴스, What's New 공지, 가이드북(PDF), 성공수기, 멘토, 멘토링 Q&A, 아카데미 교육, 출국전 오리엔테이션, 인턴 공모전. 예: '해외취업 가이드북 있어?', '독일 취업 성공수기 보여줘', '해외취업 멘토 누구 있어?'

| 파라미터 | 구분 | 설명 |
|---|---|---|
| `kind` | **필수** 값: programs, sites, schedule, careerStats | programs(교육과정)·sites(교육장)·schedule(접수일정)·careerStats(국가별 경력·학력) |

| `limit` | 선택 | 최대 결과 수 (기본 15) |
